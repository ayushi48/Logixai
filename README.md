## 📊 Core Modules

| Module | Description |
|----------|------------|
| 🤖 AI Chat Assistant | Intelligent conversational AI for answering questions, content generation, and problem-solving |
| 🌐 AI Website Builder | Generates responsive websites from user prompts with HTML, CSS, and JavaScript |
| 🖼️ Image Converter | Converts images between PNG, JPG, JPEG, WEBP, and AVIF formats |
| ✂️ Background Remover | Removes image backgrounds using AI-powered segmentation |
| 🔐 Authentication System | Secure login, signup, token management, and protected routes |
| 📁 Upload Manager | Handles image uploads, validation, and processing |
| ⚡ REST API Services | Backend APIs for AI interactions and image processing |
| 📱 Responsive Interface | Optimized experience across desktop, tablet, and mobile devices |

## 🚀 Getting Started

```bash
# 1. Clone the repository
git clone https://github.com/ayushi48/ai.git

# 2. Navigate into the project
cd Logixai

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
```
